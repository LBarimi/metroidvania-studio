패키지와 준비 사항
- 현재 패키지는 Unreal Engine 5용 소스 플러그인입니다.
- ZIP 전체를 먼저 압축 해제하세요. .uplugin과 Source 폴더가 함께 필요합니다.

웹 스튜디오 실행
스튜디오 배포본 폴더에서 운영체제에 맞는 스크립트를 실행합니다.
브라우저가 열리면 맵을 편집하고 방 JSON을 내보냅니다.
  Windows: platform/win/web/run.bat
  Linux  : bash platform/linux/run.sh
  macOS  : platform/mac/run.command

Windows 설치
1. 대상 Unreal 프로젝트를 닫습니다.
2. 압축을 푼 폴더의 install.bat를 실행하고 대상 .uproject 파일을 선택합니다.
3. 프로젝트를 열고 플러그인 활성화 상태를 확인합니다.
   설치 위치: <프로젝트>/Plugins/MetroidvaniaStudio

엔진을 자동으로 찾지 못하면 PowerShell에서 압축을 푼 폴더로 이동한 뒤:
  .\Install-Integration.ps1 -ProjectFile "<project.uproject>" -EngineRoot "<engine-root>"
꺾쇠 부분은 실제 프로젝트 파일과 엔진 설치 폴더로 바꿉니다.

수동 설치 (Windows / Linux / macOS)
ZIP의 plugin/MetroidvaniaStudio 폴더를 프로젝트의 Plugins 아래에 복사하고,
대상 엔진과 운영체제의 C++ 도구로 프로젝트의 Editor 타깃을 빌드하세요.
필요하면 프로젝트 파일을 다시 생성하고 플러그인을 활성화합니다.

샘플 방 불러오기
1. 레벨에 MetroidvaniaStudioRoom 액터를 배치합니다.
2. 액터의 Details > Metroidvania Studio > Import에서 아래 파일을 지정합니다.
   경로는 압축을 푼 폴더 기준입니다.
     Map File          : plugin/MetroidvaniaStudio/samples/maps/Sample.map.json
     Catalog File      : plugin/MetroidvaniaStudio/samples/catalog.json
     Resource Directory: plugin/MetroidvaniaStudio/samples
     Room Id           : 비워두면 첫 번째 방
3. Import Room을 누르고 레벨을 저장합니다.
   설치된 프로젝트에서도 Plugins/MetroidvaniaStudio/samples를 사용할 수 있습니다.

내 맵 불러오기와 다시 불러오기
- 내보낸 맵 JSON, 대응하는 catalog.json, 텍스처의 리소스 루트를 지정합니다.
- 리소스 루트는 catalog의 asset 상대 경로가 시작되는 폴더입니다.
  예: textures/Terrain.png가 있으면 textures 폴더의 상위를 선택합니다.
- 방 이름 대신 JSON의 안정적인 방 ID를 Room Id에 넣어 특정 방을 선택합니다.
- 맵을 수정했으면 Import Room을 다시 누릅니다. 자동 동기화는 아직 미지원입니다.
- Rebuild Room은 액터에 저장된 데이터로 재생성합니다. 원본 파일을 다시 읽으려면
  Import Room을 사용하세요. Clear Room은 가져온 방을 제거합니다.
- JSON과 PNG 데이터는 액터에 저장됩니다. 레벨 저장 후에는 원본 파일이 없어도
  재생성할 수 있으며, 게임 실행 시 이 플러그인이 함께 필요합니다.

픽셀퍼펙트 카메라
플레이어 컨트롤러의 View Target을 가져온 방 액터로 지정하세요.
RoomCamera가 내보낸 기준 해상도(기본 320x180)로 렌더링하고 PPU(기본 16)에
맞춰 시야를 픽셀에 정렬합니다. 이미지는 보간 없이 정수 배율로 확대됩니다.
남는 공간은 검게 표시하며, 창이 기준 해상도보다 작으면 1배 크기로 잘라서
표시합니다. 게임 HUD는 이 이미지 위에 배치할 수 있습니다.
카메라는 축에 정렬된 2D 시야를 기준으로 합니다.
흰색 방 경계는 레벨 편집기 전용이며 Game View에서는 숨겨집니다.
