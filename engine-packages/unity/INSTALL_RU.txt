Установка в Unity 6
Пакет подключает Unity к редактору Metroidvania Studio. Редактор и его локальный сервер запускаются отдельно.
1. Откройте свой проект в Unity.
2. Дважды щёлкните metroidvania-studio.unitypackage или выберите его через Assets > Import Package > Custom Package.
3. Отметьте все файлы и нажмите Import. Пакет установится в Assets/MetroidvaniaStudioIntegration. В этой же папке находятся инструкции INSTALL_*.txt.

Запуск Metroidvania Studio
Распакуйте архив редактора целиком. Запустите файл в корне архива:
  Windows (архив win) : metroidvania-studio.exe
  Windows (архив web) : metroidvania-studio.bat
  macOS               : metroidvania-studio.command
  Linux               : bash ./metroidvania-studio.sh
Если вы скачали исходный код из Git, используйте скрипт для своей ОС:
  Windows : platform/win/web/run.bat
  Linux   : bash platform/linux/run.sh
  macOS   : platform/mac/run.command

Подключение и импорт комнаты
1. В Unity откройте Tools > Metroidvania Studio.
2. Введите локальный адрес запущенного редактора и нажмите Connect / Refresh. Адрес по умолчанию — http://127.0.0.1:18765/.
3. Выберите комнату и нажмите Load / Reload room. Она появится в активной сцене. Сохраните сцену.
4. Включите Follow web edits и оставьте окно подключения открытым. Изменения комнаты из редактора будут появляться в Unity. В режиме игры обновление приостанавливается.
5. Remove imported room удаляет созданные адаптером комнаты в активной сцене. Повторная загрузка заменяет комнату. Размещайте собственную игровую логику вне созданной иерархии. Ручной импорт и удаление поддерживают Undo. Автоматические обновления не добавляют записи в историю Undo.

Данные и камера
Текстуры и ресурсы сохраняются в Assets/MetroidvaniaStudioImports. Сохранённая сцена работает и после отключения редактора. Для запуска игры нужны код из папки Runtime пакета и импортированные ресурсы.
Адаптер импортирует рельеф, объекты, триггеры и метаданные. Поведение игры задаётся в вашем проекте.
При загрузке основная камера центрируется на комнате. Если камеры нет, адаптер создаёт её. StudioPixelCamera управляет размером камеры и целочисленным масштабом изображения. PPU и базовое разрешение берутся из редактора. Значения по умолчанию — 16 и 320×180.

Где найти файлы редактора
В меню «Файл» выберите «Папки хранения», чтобы увидеть пути к Maps и Textures.
По умолчанию они находятся рядом с программой запуска или в корне проекта с исходным кодом:
  JSON комнаты    : Maps/AutoExport/<папка карты>/<имя комнаты>.json
  Каталог         : .studio/catalog.json
  Каталог ресурсов: папка, содержащая Maps и Textures
При переносе на другой компьютер скопируйте JSON, каталог и текстуры.
