Установка в Unreal Engine 4.27
Распакуйте ZIP целиком. Это плагин в исходном коде. Файл MetroidvaniaStudio.uplugin и папка Source должны оставаться вместе.

Запуск Metroidvania Studio
Распакуйте архив редактора целиком. Запустите файл в корне архива:
  Windows (архив win) : metroidvania-studio.exe
  Windows (архив web) : metroidvania-studio.bat
  macOS               : metroidvania-studio.command
  Linux               : bash ./metroidvania-studio.sh
Если вы скачали исходный код из Git, используйте скрипт для своей ОС:
  Windows : platform/win/web/run.bat
  Linux   : bash platform/linux/run.sh
  macOS   : platform/mac/run.command

Установка плагина
В Windows закройте целевой проект, запустите install.bat из распакованной папки и выберите файл .uproject. Затем откройте проект и проверьте, что плагин включён. Он устанавливается в <проект>/Plugins/MetroidvaniaStudio.
Если установщик не нашёл движок, откройте PowerShell в распакованной папке и выполните:
  .\Install-Integration.ps1 -ProjectFile "<project.uproject>" -EngineRoot "<engine-root>"
Подставьте путь к .uproject и корневую папку движка.
Для ручной установки скопируйте plugin/MetroidvaniaStudio в папку Plugins проекта. При необходимости заново создайте файлы проекта. Соберите цель Editor инструментами C++ для своей версии движка и платформы, затем включите плагин.

Импорт примера
Поместите на уровень актор MetroidvaniaStudioRoom. В Details > Metroidvania Studio > Import укажите пути относительно распакованного архива:
  Map File           : plugin/MetroidvaniaStudio/samples/maps/Sample.map.json
  Catalog File       : plugin/MetroidvaniaStudio/samples/catalog.json
  Resource Directory : plugin/MetroidvaniaStudio/samples
  Room Id            : оставьте пустым для загрузки первой комнаты
После установки копия примера находится в Plugins/MetroidvaniaStudio/samples. Нажмите Import Room и сохраните уровень.

Импорт своей карты
Выберите JSON карты, соответствующий каталог и корневую папку ресурсов. Относительные пути asset отсчитываются от этой папки. Сохраняйте регистр букв. В Room Id указывается постоянный ID комнаты из JSON.
После правок нажмите Import Room, чтобы перечитать файлы. Rebuild Room перестраивает комнату из встроенных данных, а Clear Room очищает её. Обновление выполняется вручную. JSON и байты PNG сохраняются в акторе. Для работы сохранённого уровня нужен плагин, даже если исходные файлы уже перемещены.

Камера
Назначьте импортированный актор комнаты целью обзора игрового контроллера (View Target). RoomCamera отображает комнату в экспортированном разрешении (по умолчанию 320×180) и привязывает вид к исходным пикселям с учётом PPU (по умолчанию 16). Изображение выводится с целочисленным масштабом и фильтрацией по ближайшему соседу. Свободное место остаётся чёрным. Если окно меньше базового разрешения, изображение обрезается при масштабе 1×.
Камера рассчитана на 2D-вид вдоль координатных осей. Виджеты HUD можно разместить поверх изображения. Белые границы комнат видны в редакторе уровня и скрываются в Game View.

Где найти файлы редактора
В меню «Файл» выберите «Папки хранения», чтобы увидеть пути к Maps и Textures.
По умолчанию они находятся рядом с программой запуска или в корне проекта с исходным кодом:
  JSON комнаты    : Maps/AutoExport/<папка карты>/<имя комнаты>.json
  Каталог         : .studio/catalog.json
  Каталог ресурсов: папка, содержащая Maps и Textures
При переносе на другой компьютер скопируйте JSON, каталог и текстуры.
