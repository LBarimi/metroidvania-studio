準備工作
- 此外掛適用於 Godot 4。請先解壓縮整個 ZIP 檔案。

啟動網頁編輯器
在編輯器發行資料夾中，執行對應作業系統的指令碼。
瀏覽器開啟後，即可編輯地圖並匯出房間 JSON。
  Windows: platform/win/web/run.bat
  Linux  : bash platform/linux/run.sh
  macOS  : platform/mac/run.command

Windows 安裝
1. 關閉目標 Godot 專案。
2. 執行解壓縮資料夾中的 install.bat。
3. 選取目標專案的 project.godot 檔案。
4. 安裝完成後開啟專案，即可看到 Metroidvania Studio 面板。
   安裝程式會複製外掛並將其啟用。

手動安裝 (Windows / Linux / macOS)
1. 將 addons/metroidvania-studio 複製到專案的 addons 資料夾下。
   最終路徑：<project>/addons/metroidvania-studio/plugin.cfg
2. 在 Project > Project Settings > Plugins 中啟用 Metroidvania Studio。
   選單名稱會隨編輯器語言變化。

匯入範例房間
在面板中依序設定以下項目，路徑皆相對於 ZIP 的解壓縮資料夾：
  Map JSON        : samples/maps/Sample.map.json
  Catalog JSON    : samples/catalog.json
  Resource folder : samples
選取房間並按下 Import / Reload room。
產生的 .tscn 會儲存至 res://metroidvania-studio-imports 並開啟。
請將此場景作為實例放入自己的遊戲場景中使用。

匯入自己的地圖及重新匯入
- 需要地圖 JSON、對應的 catalog.json，以及貼圖的資源根目錄。
- 若 catalog 中的 asset 為 textures/Terrain.png，資源根目錄應選擇
  textures 的上層資料夾。請保留檔案名稱與路徑的大小寫。
- 編輯地圖後，以相同輸入再次按下 Import / Reload room。目前尚未支援自動同步。
- 相同房間 ID 的產生場景會被覆寫。請將遊戲邏輯放在獨立場景，並實例化產生場景。
- 產生的場景內嵌貼圖，但執行時仍需要外掛的執行階段腳本。

像素完美顯示
匯入時保持 Configure pixel-perfect display 開啟，即可將地圖的
reference_resolution（預設320x180）、視埠繪製及整數倍縮放套用至專案設定。
若要自行管理顯示設定，請關閉此選項。RoomCamera 使用匯出的PPU（預設16），
僅將視圖對齊像素，不改變攝影機節點的位置。請用 view_offset 調整取景偏移。
此攝影機停用平滑。白色房間邊界只在2D編輯器顯示，不會出現在執行中的遊戲。

工作室檔案位置
在檔案 > 儲存資料夾中尋找Maps和Textures。
預設儲存在啟動檔案旁或原始碼專案根目錄。
  房間JSON : Maps/AutoExport/<地圖資料夾>/<房間名稱>.json
  目錄檔案 : catalog.json
  資源目錄 : 包含Maps、Textures和catalog.json的資料夾
移至另一台電腦時請一起複製這三項。
