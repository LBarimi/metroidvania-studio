小地圖

兩個小地圖分頁都能平移、縮放及開啟房間。在 編輯小地圖 中放置、移動或刪除圖塊。

操作按鍵或滑鼠
平移視圖中鍵拖曳 / Alt + 左鍵拖曳
放大或縮小滾輪
在地圖編輯器開啟房間連按兩下房間
放置選取的房間圖塊點選空白網格
移動房間左鍵拖曳
刪除房間圖塊右鍵點擊
