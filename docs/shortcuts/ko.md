# 단축키

맵 편집, 미니맵, Game Preview에서 자주 쓰는 키와 마우스 조작을 작업별로 모았습니다. 편집기의 **도움말 → 단축키**에서 이 페이지를 열 수 있습니다.

[English](../shortcuts.md) · 한국어 · [日本語](ja.md) · [简体中文](zh-hans.md) · [繁體中文](zh-hant-tw.md) · [Русский](ru.md)

## 파일과 편집

| 작업 | Windows / Linux | macOS |
| --- | --- | --- |
| 맵 저장 | `Ctrl + S` | `⌘ + S` |
| 맵 다른 이름으로 저장 | `Ctrl + Shift + S` | `⌘ + Shift + S` |
| 실행 취소 | `Ctrl + Z` | `⌘ + Z` |
| 다시 실행 | `Ctrl + Y / Ctrl + Shift + Z` | `⌘ + Y / ⌘ + Shift + Z` |
| 복사 | `Ctrl + C` | `⌘ + C` |
| 잘라내기 | `Ctrl + X` | `⌘ + X` |
| 붙여넣기 | `Ctrl + V` | `⌘ + V` |
| 모두 선택 | `Ctrl + A` | `⌘ + A` |
| 선택한 방·내용 삭제 | `Delete / Backspace` | `Delete / Backspace` |

## 맵 이동과 방 편집

| 작업 | 입력 |
| --- | --- |
| 화면 이동 | `휠클릭 드래그 / Alt + 좌클릭 드래그` |
| 확대·축소 | `휠` |
| 방 보기 | `F` |
| 방 선택 | `다른 방 클릭` |
| 방 이동 | `방 이름 막대 드래그` |
| 방 크기 조절 | `외부 핸들 드래그` |
| 방 선택 추가·해제 | `Ctrl / ⌘ + 좌클릭` |
| 선택한 방 함께 이동 | `좌클릭 드래그` |
| 방 생성 메뉴 (빈 공간) | `우클릭` |
| 화면 이동 (빈 공간) | `우클릭 드래그` |

## 도구 선택

캔버스에서 키를 누르면 도구가 바뀝니다. 오브젝트 레이어에서 **B**를 누르면 전경 타일 레이어의 브러시로 전환합니다.

| 작업 | 입력 |
| --- | --- |
| 방 | `R` |
| 오브젝트 배치 | `P` |
| 타일 영역 선택 / 오브젝트 선택 | `V` |
| 브러시 | `B` |
| 사각형 | `U` |
| 채우기 | `G` |
| 직선 | `L` |
| 원 | `C` |
| 타원 | `E` |

## 타일과 오브젝트

| 작업 | 입력 |
| --- | --- |
| 타일 그리기 | `좌클릭 드래그` |
| 방 안에서 지우기 | `우클릭` |
| 브러시 크기 조절 | `Ctrl + 휠` |
| 커서 아래 타일 집기 | `Ctrl / ⌘ + 우클릭` |
| 타일 영역 선택 (선택 도구) | `좌클릭 드래그` |
| 선택 영역 이동 | `선택 영역 안쪽 드래그` |
| 새 영역 선택 (선택 도구) | `Shift + 좌클릭 드래그` |
| 오브젝트 배치 | `팔레트 선택 후 클릭` |
| 영역 오브젝트 크기 지정 | `좌클릭 드래그` |
| 오브젝트 속성 | `Ctrl / ⌘ + 우클릭` |
| 노드 선택 | `노드 클릭` |
| 취소 | `Esc` |

## 미니맵

두 미니맵 탭에서 화면 이동, 확대·축소, 방 열기를 할 수 있습니다. 맵칩 배치·이동·삭제는 **미니맵 편집**에서 합니다.

| 작업 | 입력 |
| --- | --- |
| 화면 이동 | `휠클릭 드래그 / Alt + 좌클릭 드래그` |
| 확대·축소 | `휠` |
| 맵 편집에서 방 열기 | `방 더블클릭` |
| 선택한 맵칩 배치 | `빈 격자 클릭` |
| 방 이동 | `좌클릭 드래그` |
| 맵칩 삭제 | `우클릭` |
| 실행 취소 | `Ctrl / ⌘ + Z` |
| 방 보기 (미니맵 보기) | `F` |

## Game Preview와 메뉴

| 작업 | 입력 |
| --- | --- |
| Game Preview 안에서 카메라 이동 | `좌클릭 드래그` |
| Game Preview에 포커스가 있을 때 방 중앙으로 이동 | `F` |
| 최대화한 미리보기 원래 크기로 복원 | `Esc` |
| 파일 | `Alt + F` |
| 편집 | `Alt + E` |
| 도움말 | `Alt + H` |
