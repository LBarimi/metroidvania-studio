# Горячие клавиши

Клавиши и действия мышью для карты, мини-карты и Game Preview собраны по задачам. Страница открывается через меню **Справка → Горячие клавиши**.

[English](../shortcuts.md) · [한국어](ko.md) · [日本語](ja.md) · [简体中文](zh-hans.md) · [繁體中文](zh-hant-tw.md) · Русский

## Файлы и редактирование

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Сохранить карту | `Ctrl + S` | `⌘ + S` |
| Сохранить карту как | `Ctrl + Shift + S` | `⌘ + Shift + S` |
| Отменить | `Ctrl + Z` | `⌘ + Z` |
| Повторить | `Ctrl + Y / Ctrl + Shift + Z` | `⌘ + Y / ⌘ + Shift + Z` |
| Копировать | `Ctrl + C` | `⌘ + C` |
| Вырезать | `Ctrl + X` | `⌘ + X` |
| Вставить | `Ctrl + V` | `⌘ + V` |
| Выделить всё | `Ctrl + A` | `⌘ + A` |
| Удалить выбранную комнату или содержимое | `Delete / Backspace` | `Delete / Backspace` |

## Навигация и комнаты

| Действие | Клавиши или мышь |
| --- | --- |
| Перемещать вид | `Средняя + движение / Alt + Левая + движение` |
| Изменить масштаб | `Колесо` |
| Показать комнату | `F` |
| Выбрать комнату | `Щёлкнуть другую комнату` |
| Переместить комнату | `Тянуть полосу названия` |
| Изменить размер комнаты | `Тянуть внешний маркер` |
| Добавить или убрать комнату из выбора | `Ctrl / ⌘ + Левая кнопка мыши` |
| Переместить выбранные комнаты вместе | `Левая + движение` |
| Меню комнаты на пустом месте | `Правая кнопка` |
| Перемещать вид с пустого места | `Правая + движение` |

## Выбор инструмента

Нажмите клавишу над холстом, чтобы сменить инструмент. На слое объектов клавиша **B** переключает на кисть переднего слоя тайлов.

| Действие | Клавиши или мышь |
| --- | --- |
| Правка комнат | `R` |
| Размещение объектов | `P` |
| Выделение тайлов / Выделение объектов | `V` |
| Кисть | `B` |
| Прямоугольник | `U` |
| Заливка | `G` |
| Линия | `L` |
| Круг | `C` |
| Эллипс | `E` |

## Тайлы и объекты

| Действие | Клавиши или мышь |
| --- | --- |
| Рисовать тайлы | `Левая + движение` |
| Стирать внутри комнаты | `Правая кнопка` |
| Изменить размер кисти | `Ctrl + Колесо` |
| Взять тайл под курсором | `Ctrl / ⌘ + Правая кнопка` |
| Выделить тайлы (инструмент выделения) | `Левая + движение` |
| Переместить выделение | `Тянуть внутри выделения` |

| Задать размер объекта-области | `Левая + движение` |
| Свойства объекта | `Ctrl / ⌘ + Правая кнопка` |

## Мини-карта

В обоих режимах мини-карты можно перемещать вид, менять масштаб и открывать комнаты. На вкладке **Редактор мини-карты** выберите шаблон в панели **Шаблоны комнат** и щёлкните по свободной клетке, чтобы разместить комнату.

| Действие | Клавиши или мышь |
| --- | --- |
| Перемещать вид | `Средняя + движение / Alt + Левая + движение` |
| Изменить масштаб | `Колесо` |
| Открыть комнату в редакторе карты | `Двойной щелчок по комнате` |
| Разместить комнату по выбранному шаблону | `Щелчок по свободной клетке` |
| Переместить комнату | `Левая + движение` |
| Удалить комнату | `Правая кнопка` |
| Отменить | `Ctrl / ⌘ + Z` |
| Показать комнату (Просмотр мини-карты) | `F` |

| Действие | Клавиши или мышь |

| Переместить камеру внутри Game Preview | `Левая + движение` |
