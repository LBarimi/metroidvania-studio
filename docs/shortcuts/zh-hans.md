# 快捷键

按任务查找地图编辑器、小地图和 Game Preview 的键盘与鼠标操作。通过编辑器的 **帮助 → 快捷键** 打开此页。

[English](../shortcuts.md) · [한국어](ko.md) · [日本語](ja.md) · 简体中文 · [繁體中文](zh-hant-tw.md) · [Русский](ru.md)

## 文件与编辑

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 保存地图 | `Ctrl + S` | `⌘ + S` |
| 地图另存为 | `Ctrl + Shift + S` | `⌘ + Shift + S` |
| 撤销 | `Ctrl + Z` | `⌘ + Z` |
| 重做 | `Ctrl + Y / Ctrl + Shift + Z` | `⌘ + Y / ⌘ + Shift + Z` |
| 复制 | `Ctrl + C` | `⌘ + C` |
| 剪切 | `Ctrl + X` | `⌘ + X` |
| 粘贴 | `Ctrl + V` | `⌘ + V` |
| 全选 | `Ctrl + A` | `⌘ + A` |
| 删除所选房间或内容 | `Delete / Backspace` | `Delete / Backspace` |

## 地图导航与房间

| 操作 | 按键或鼠标 |
| --- | --- |
| 平移视图 | `中键拖动 / Alt + 左键拖动` |
| 放大或缩小 | `滚轮` |
| 显示当前房间 | `F` |
| 选择房间 | `单击其他房间` |
| 移动房间 | `拖动房间名称条` |
| 调整房间大小 | `拖动外侧控制点` |
| 添加或取消房间选择 | `Ctrl / ⌘ + 左键点击` |
| 一起移动所选房间 | `左键拖动` |
| 空白处的房间菜单 | `右键单击` |
| 从空白处平移 | `右键拖动` |

## 工具切换

在画布上按键切换工具。在对象图层按 **B** 会切换到前景图块图层的笔刷。

| 操作 | 按键或鼠标 |
| --- | --- |
| 房间编辑 | `R` |
| 放置对象 | `P` |
| 图块区域选择 / 选择对象 | `V` |
| 笔刷 | `B` |
| 矩形 | `U` |
| 填充 | `G` |
| 直线 | `L` |
| 圆 | `C` |
| 椭圆 | `E` |

## 图块与对象

| 操作 | 按键或鼠标 |
| --- | --- |
| 绘制图块 | `左键拖动` |
| 擦除房间内的内容 | `右键单击` |
| 调整笔刷大小 | `Ctrl + 滚轮` |
| 拾取指针下的图块 | `Ctrl / ⌘ + 右键单击` |
| 选择图块区域（选择工具） | `左键拖动` |
| 移动所选区域 | `在选区内拖动` |
| 新区域（选择工具） | `Shift + 左键拖动` |
| 放置对象 | `在调色板中选择后单击` |
| 设置区域对象大小 | `左键拖动` |
| 对象属性 | `Ctrl / ⌘ + 右键单击` |
| 选择节点 | `单击节点` |
| 取消 | `Esc` |

## 小地图

两个小地图页签都支持平移、缩放和打开房间。在 **编辑小地图** 中放置、移动或删除图块。

| 操作 | 按键或鼠标 |
| --- | --- |
| 平移视图 | `中键拖动 / Alt + 左键拖动` |
| 放大或缩小 | `滚轮` |
| 在地图编辑器中打开房间 | `双击房间` |
| 放置选定的房间图块 | `单击空网格` |
| 移动房间 | `左键拖动` |
| 删除房间图块 | `右键单击` |
| 撤销 | `Ctrl / ⌘ + Z` |
| 显示当前房间 (查看小地图) | `F` |

## Game Preview 与菜单

| 操作 | 按键或鼠标 |
| --- | --- |
| 在 Game Preview 中平移相机 | `左键拖动` |
| Game Preview 获得焦点时回到房间中心 | `F` |
| 还原最大化预览 | `Esc` |
| 文件 | `Alt + F` |
