# ショートカット

マップ編集、ミニマップ、Game Preview のキーとマウス操作を作業別にまとめました。エディターの **ヘルプ → ショートカット** から開けます。

[English](../shortcuts.md) · [한국어](ko.md) · 日本語 · [简体中文](zh-hans.md) · [繁體中文](zh-hant-tw.md) · [Русский](ru.md)

## ファイルと編集

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| マップを保存 | `Ctrl + S` | `⌘ + S` |
| マップを別名で保存 | `Ctrl + Shift + S` | `⌘ + Shift + S` |
| 元に戻す | `Ctrl + Z` | `⌘ + Z` |
| やり直す | `Ctrl + Y / Ctrl + Shift + Z` | `⌘ + Y / ⌘ + Shift + Z` |
| コピー | `Ctrl + C` | `⌘ + C` |
| 切り取り | `Ctrl + X` | `⌘ + X` |
| 貼り付け | `Ctrl + V` | `⌘ + V` |
| すべて選択 | `Ctrl + A` | `⌘ + A` |
| 選択した部屋・内容を削除 | `Delete / Backspace` | `Delete / Backspace` |

## マップの移動と部屋の編集

| 操作 | 入力 |
| --- | --- |
| 表示を移動 | `中ドラッグ / Alt + 左ドラッグ` |
| ズームイン・ズームアウト | `ホイール` |
| 部屋を表示 | `F` |
| 部屋を選択 | `別の部屋をクリック` |
| 部屋を移動 | `部屋名の帯をドラッグ` |
| 部屋のサイズ変更 | `外側ハンドルをドラッグ` |
| 部屋の選択を追加・解除 | `Ctrl / ⌘ + 左クリック` |
| 選択した部屋をまとめて移動 | `左ドラッグ` |
| 空白で部屋メニュー | `右クリック` |
| 空白から表示を移動 | `右ドラッグ` |

## ツールの切り替え

キャンバス上でキーを押してツールを切り替えます。オブジェクトレイヤーで **B** を押すと前景タイルのブラシに切り替わります。

| 操作 | 入力 |
| --- | --- |
| 部屋の編集 | `R` |
| オブジェクト配置 | `P` |
| タイル領域選択 / オブジェクト選択 | `V` |
| ブラシ | `B` |
| 長方形 | `U` |
| 塗りつぶし | `G` |
| 直線 | `L` |
| 円 | `C` |
| 楕円 | `E` |

## タイルとオブジェクト

| 操作 | 入力 |
| --- | --- |
| タイルを描画 | `左ドラッグ` |
| 部屋内を消去 | `右クリック` |
| ブラシサイズ変更 | `Ctrl + ホイール` |
| カーソル下のタイルを取得 | `Ctrl / ⌘ + 右クリック` |
| タイル領域選択（選択ツール） | `左ドラッグ` |
| 選択領域を移動 | `選択領域の内側をドラッグ` |
| 新しい領域（選択ツール） | `Shift + 左ドラッグ` |
| オブジェクト配置 | `パレットで選んでクリック` |
| 領域オブジェクトのサイズ | `左ドラッグ` |
| オブジェクトのプロパティ | `Ctrl / ⌘ + 右クリック` |
| ノード選択 | `ノードをクリック` |
| キャンセル | `Esc` |

## ミニマップ

どちらのミニマップでも移動、ズーム、部屋を開く操作が使えます。チップの配置・移動・削除は **ミニマップ編集** で行います。

| 操作 | 入力 |
| --- | --- |
| 表示を移動 | `中ドラッグ / Alt + 左ドラッグ` |
| ズームイン・ズームアウト | `ホイール` |
| マップ編集で部屋を開く | `部屋をダブルクリック` |
| 選択したチップを配置 | `空きマスをクリック` |
| 部屋を移動 | `左ドラッグ` |
| 部屋チップを削除 | `右クリック` |
| 元に戻す | `Ctrl / ⌘ + Z` |
| 部屋を表示 (ミニマップ表示) | `F` |

## Game Preview とメニュー

| 操作 | 入力 |
| --- | --- |
| Game Preview 内でカメラを移動 | `左ドラッグ` |
| Game Preview にフォーカス中、部屋の中央に戻る | `F` |
| 最大化したプレビューを元に戻す | `Esc` |
| ファイル | `Alt + F` |
| 編集 | `Alt + E` |
| ヘルプ | `Alt + H` |
