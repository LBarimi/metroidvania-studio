# 快速鍵

依工作查找地圖、小地圖及 Game Preview 的鍵盤與滑鼠操作。從編輯器的 **說明 → 快速鍵** 可開啟此頁。

[English](../shortcuts.md) · [한국어](ko.md) · [日本語](ja.md) · [简体中文](zh-hans.md) · 繁體中文 · [Русский](ru.md)

## 檔案與編輯

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 儲存地圖 | `Ctrl + S` | `⌘ + S` |
| 地圖另存新檔 | `Ctrl + Shift + S` | `⌘ + Shift + S` |
| 復原 | `Ctrl + Z` | `⌘ + Z` |
| 重做 | `Ctrl + Y / Ctrl + Shift + Z` | `⌘ + Y / ⌘ + Shift + Z` |
| 複製 | `Ctrl + C` | `⌘ + C` |
| 剪下 | `Ctrl + X` | `⌘ + X` |
| 貼上 | `Ctrl + V` | `⌘ + V` |
| 全選 | `Ctrl + A` | `⌘ + A` |
| 刪除所選房間或內容 | `Delete / Backspace` | `Delete / Backspace` |

## 地圖導覽與房間

| 操作 | 按鍵或滑鼠 |
| --- | --- |
| 平移視圖 | `中鍵拖曳 / Alt + 左鍵拖曳` |
| 放大或縮小 | `滾輪` |
| 顯示目前房間 | `F` |
| 選取房間 | `點擊其他房間` |
| 移動房間 | `拖曳房間名稱列` |
| 調整房間大小 | `拖曳外側控制點` |
| 新增或取消房間選取 | `Ctrl / ⌘ + 左鍵點擊` |
| 一起移動所選房間 | `左鍵拖曳` |
| 空白處的房間選單 | `右鍵點擊` |
| 從空白處平移 | `右鍵拖曳` |

## 工具切換

在畫布上按鍵可切換工具。在物件圖層按 **B** 會切換到前景圖塊圖層的筆刷。

| 操作 | 按鍵或滑鼠 |
| --- | --- |
| 房間編輯 | `R` |
| 放置物件 | `P` |
| 圖塊區域選取 / 選取物件 | `V` |
| 筆刷 | `B` |
| 矩形 | `U` |
| 填滿 | `G` |
| 直線 | `L` |
| 圓形 | `C` |
| 橢圓形 | `E` |

| 操作 | 按鍵或滑鼠 |
| --- | --- |
| 繪製圖塊 | `左鍵拖曳` |
| 清除房間內的內容 | `右鍵點擊` |

| 選取游標下的圖塊 | `Ctrl / ⌘ + 右鍵點擊` |

## 小地圖

兩個小地圖分頁都能平移、縮放及開啟房間。在 **編輯小地圖** 中放置、移動或刪除圖塊。

| 操作 | 按鍵或滑鼠 |
| --- | --- |
| 平移視圖 | `中鍵拖曳 / Alt + 左鍵拖曳` |
| 放大或縮小 | `滾輪` |
| 在地圖編輯器開啟房間 | `連按兩下房間` |
| 放置選取的房間圖塊 | `點選空白網格` |
| 移動房間 | `左鍵拖曳` |
| 刪除房間圖塊 | `右鍵點擊` |
| 復原 | `Ctrl / ⌘ + Z` |
| 顯示目前房間 (檢視小地圖) | `F` |

## Game Preview 與選單

| 操作 | 按鍵或滑鼠 |
| --- | --- |
| 在 Game Preview 內平移攝影機 | `左鍵拖曳` |
| Game Preview 有焦點時回到房間中心 | `F` |
