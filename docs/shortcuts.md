# Keyboard shortcuts

Find a key or mouse gesture by the task you are doing in the editor. Open this page from **Help → Shortcuts**.

English · [한국어](shortcuts/ko.md) · [日本語](shortcuts/ja.md) · [简体中文](shortcuts/zh-hans.md) · [繁體中文](shortcuts/zh-hant-tw.md) · [Русский](shortcuts/ru.md)

## Files and editing

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Save map | `Ctrl + S` | `⌘ + S` |
| Save map as | `Ctrl + Shift + S` | `⌘ + Shift + S` |
| Undo | `Ctrl + Z` | `⌘ + Z` |
| Redo | `Ctrl + Y / Ctrl + Shift + Z` | `⌘ + Y / ⌘ + Shift + Z` |
| Copy | `Ctrl + C` | `⌘ + C` |
| Cut | `Ctrl + X` | `⌘ + X` |
| Paste | `Ctrl + V` | `⌘ + V` |
| Select all | `Ctrl + A` | `⌘ + A` |
| Delete selected room or content | `Delete / Backspace` | `Delete / Backspace` |

## Map navigation and rooms

| Action | Input |
| --- | --- |
| Pan view | `Middle drag / Alt + Left drag` |
| Zoom in or out | `Wheel` |
| Frame room | `F` |
| Select room | `Click another room` |
| Move room | `Drag room title strip` |
| Resize room | `Drag outer handle` |
| Toggle room selection | `Ctrl / ⌘ + Left click` |
| Move selected rooms together | `Left drag` |
| Room menu on empty space | `Right click` |
| Pan from empty space | `Right drag` |

## Tools

Press a tool key while editing the canvas. **B** also switches to the foreground tile layer when an object layer is active.

| Action | Input |
| --- | --- |
| Rooms | `R` |
| Place objects | `P` |
| Select tile area / Select objects | `V` |
| Brush | `B` |
| Rectangle | `U` |
| Bucket | `G` |
| Line | `L` |
| Circle | `C` |
| Ellipse | `E` |

## Minimap

Both minimap tabs support panning, zooming and opening a room. Place, move and remove chips in **Edit minimap**.

| Action | Input |
| --- | --- |
| Pan view | `Middle drag / Alt + Left drag` |
| Zoom in or out | `Wheel` |
| Open room in Map editor | `Double-click a room` |
| Place the selected chip | `Click empty grid space` |
| Move room | `Left drag` |
| Remove a room chip | `Right click` |
| Undo | `Ctrl / ⌘ + Z` |
| Frame room (View minimap) | `F` |
